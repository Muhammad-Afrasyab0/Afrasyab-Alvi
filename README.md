🖥️ GitHub Usage
You can use the SVG files as visual profile assets in your GitHub profile repository.
For example:
```html
<p align="center">
  <img src="./dark.svg" alt="Muhammad Afrasyab Developer Profile" width="100%">
</p>
```
For the light version:
```html
<p align="center">
  <img src="./light.svg" alt="Muhammad Afrasyab Developer Profile" width="100%">
</p>
```
You can also embed the SVG through Markdown:
```md
![Muhammad Afrasyab Developer Profile](./dark.svg)
```
